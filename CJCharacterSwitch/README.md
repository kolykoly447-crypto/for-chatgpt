# CJ Character Switch — Minecraft 1.20.1 (Forge)

Forge mod project targeting Minecraft 1.20.1 / Forge 47.4.29 / Java 17.

## Build
Run `gradle --no-daemon clean build` from this folder. The included GitHub Actions workflow builds it automatically and publishes the compiled JAR as a workflow artifact.

## Controls
Press **G** to toggle the local player's third-person appearance between the normal Minecraft model and an original CJ-inspired skin. Press G again to restore the usual appearance. Rebind the key in Options → Controls.

## Included
- 64×64 player skin texture inspired by CJ's Grove Street look
- Raised 3D hair-cap and gold necklace accessories
- Uses animated player model poses (walking, looking, crouching)
- Standard and slim skin model renderers
- English and Russian translations

## Limits
The current version changes only the local player's third-person appearance. It does not synchronize the appearance to other players and does not replace the first-person arms. All visual assets are original fan-made interpretations, not extracted Rockstar game assets.
